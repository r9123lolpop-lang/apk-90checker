# APK Checker

Готовый стартовый Android Studio проект на Kotlin + Jetpack Compose + Material 3.

## Возможности
- Сканирование доступных каталогов на APK/APKS и именованные остаточные файлы.
- Проверка установленных приложений через PackageManager.
- SHA-256 для найденных APK/APKS.
- Статусы «Найдено» и «Возможный остаток».
- Coroutines + MVVM.
- Честное уведомление об ограничениях Scoped Storage/root.
- APK не запускаются и не устанавливаются.

## Сборка
1. Откройте папку APKChecker в Android Studio.
2. Дождитесь Gradle Sync.
3. Подключите устройство или запустите эмулятор с Android 10+.
4. Build → Build APK(s).
5. Для release-подписи используйте Generate Signed Bundle / APK.

## Разрешение
На Android 10–12 используется READ_EXTERNAL_STORAGE с ограничением maxSdkVersion=32.
На Android 13+ приложение не запрашивает устаревшее разрешение: доступ к общему хранилищу ограничен Scoped Storage.

## Ограничение
Android не позволяет обычному приложению полноценно сканировать /data, /data/app и каталоги других приложений. Для полного глубокого анализа нужны специальные привилегии/root.
